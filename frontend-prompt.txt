ROOM API - FRONTEND INTEGRATION GUIDE
=======================================

All endpoints are prefixed with: /room

1. GET ALL ROOMS
-----------------
   Endpoint: GET /room
   Description: Fetch all rooms.
   Request body: None
   Response: Array of room objects

   mutationFn: () => axiosInstance.get("/room")

2. CREATE ROOM (with file upload)
----------------------------------
   Endpoint: POST /room
   Description: Create a new room. Send as multipart/form-data (FormData).
   The 'image' field is a FILE upload — the backend uploads it to Cloudinary
   and stores the returned URL.

   Request body (FormData):
     Field         | Type            | Required | Notes
     --------------|-----------------|----------|-------------------------------
     image         | File            | Yes      | The room's main image file
     category      | string          | Yes      |
     amenities     | string[]        | Yes      | Send as JSON array string or multiple fields
     price         | number          | Yes      | Send as string ("1200")
     discount      | number          | Yes      | Send as string ("10")
     description   | string          | Yes      | NEW: Room description text
     status        | string          | Yes      | e.g. "available", "booked", "occupied"
     maintenance   | string          | Yes      | e.g. "none", "pending", "in-progress"
     housekeeping  | string[]        | Yes      | Send as JSON array string or multiple fields
     images        | string[]        | No       | Existing image URLs (JSON array string)

   React Example:
     const formData = new FormData()
     formData.append("image", fileInput.files[0])         // the file
     formData.append("category", "Deluxe")
     formData.append("amenities", JSON.stringify(["WiFi", "TV", "Mini Bar"]))
     formData.append("price", "2500")
     formData.append("discount", "15")
     formData.append("description", "A spacious deluxe room with ocean view")
     formData.append("status", "available")
     formData.append("maintenance", "none")
     formData.append("housekeeping", JSON.stringify(["daily"]))

     axiosInstance.post("/room", formData, {
       headers: { "Content-Type": "multipart/form-data" }
     })

   Response: Array of all rooms (after creation)

   mutationFn: (formData: FormData) =>
     axiosInstance.post("/room", formData, {
       headers: { "Content-Type": "multipart/form-data" }
     })

3. UPDATE ROOM
--------------
   Endpoint: PUT /room
   Description: Update an existing room by _id.
   Note: For updating the image, send the EXISTING image URL string,
   or use the POST /room/images endpoint first to get a new URL,
   then include it here.

   Request body (JSON):
     {
       "_id": string (required),
       "category": string,
       "amenities": string[],
       "price": number,
       "discount": number,
       "image": string,        // existing Cloudinary URL
       "description": string,  // NEW: Room description
       "images": string[],     // NEW: array of image URLs
       "status": string,
       "maintenance": string,
       "housekeeping": string[]
     }
   Response: Array of all rooms (after update)

   mutationFn: (data: {
     _id: string;
     category: string;
     amenities: string[];
     price: number;
     discount: number;
     image: string;
     description: string;
     images: string[];
     status: string;
     maintenance: string;
     housekeeping: string[];
   }) => axiosInstance.put("/room", data)

4. DELETE ROOM
--------------
   Endpoint: DELETE /room
   Description: Delete a room by _id.
   Request body (JSON):
     {
       "_id": string (required)
     }
   Note: Axios sends the _id inside a `data` config option:
     axiosInstance.delete("/room", { data: { _id: id } })
   Response: Array of all rooms (after deletion)

   mutationFn: (id: string) =>
     axiosInstance.delete("/room", { data: { _id: id } })

5. UPLOAD ROOM IMAGES (MULTIPLE)
---------------------------------
   Endpoint: POST /room/images
   Description: Upload multiple images to Cloudinary and get back their URLs.
   Use these URLs to fill the room's `images[]` field (via create or update).

   Request body: multipart/form-data
     Field   | Type         | Required | Notes
     --------|--------------|----------|-----------------------
     images  | File[]       | Yes      | Up to 10 image files

   React Example:
     const formData = new FormData()
     Array.from(fileInput.files).forEach(file => {
       formData.append("images", file)
     })
     axiosInstance.post("/room/images", formData, {
       headers: { "Content-Type": "multipart/form-data" }
     })

   Response:
     {
       "urls": [
         "https://res.cloudinary.com/.../image1.jpg",
         "https://res.cloudinary.com/.../image2.jpg"
       ]
     }

   mutationFn: (formData: FormData) =>
     axiosInstance.post("/room/images", formData, {
       headers: { "Content-Type": "multipart/form-data" }
     })


ROOM SCHEMA FIELDS:
====================
| Field         | Type     | Description                                |
|---------------|----------|--------------------------------------------|
| _id           | string   | Auto-generated MongoDB ID                  |
| category      | string   | Room category (e.g. "Deluxe", "Standard")  |
| amenities     | string[] | List of amenities (e.g. ["WiFi","TV"])     |
| price         | number   | Price per night                            |
| discount      | number   | Discount percentage or amount              |
| image         | string   | Main room image URL (Cloudinary)           |
| description   | string   | Room description text                      |
| images        | string[] | Additional room image URLs (Cloudinary)    |
| status        | string   | e.g. "available", "booked", "occupied"     |
| maintenance   | string   | e.g. "none", "pending", "in-progress"      |
| housekeeping  | string[] | Housekeeping notes or schedule entries     |
